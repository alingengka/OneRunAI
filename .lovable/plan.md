# จัดระเบียบแผงเครื่องมือและซีน OneRunAI

## เป้าหมาย
ปรับเฉพาะหน้าตาและการจัดกลุ่มของแผงเครื่องมือหลักกับแผงซีนให้สะอาด อ่านง่าย และใช้งานคล่องขึ้น โดยคงธีม OneRunAI, โลโก้, Dark/Light mode และพฤติกรรมเดิมทั้งหมด

## สิ่งที่จะทำ
- เปลี่ยนแผง AI Tools จากกล่องตั้งค่าหลายใบเป็นรายการแบบแบ่งหมวด “เครื่องมือ AI” และ “ปรับแต่งวิดีโอ”
- แต่ละรายการมีไอคอน ชื่อ คำอธิบาย ปุ่มคำสั่งที่เกี่ยวข้อง และสวิตช์ด้านขวา โดยรายละเอียดภาษา/ความไว/งานบันทึกยังอยู่ครบแต่จัดเป็นพื้นที่ย่อยที่โปร่งขึ้น
- ปรับการ์ดซีนให้แสดงเลขซีน ช่วงเวลา และข้อความซับเป็นลำดับแรก
- แยกแถวฟีเจอร์ของซีนออกจากข้อความอย่างชัดเจน ใช้ปุ่มตาเปิด/ปิด และปุ่มเพิ่มท้ายแถว
- คงตัวแก้ Viral text, การเปิด/ปิดซีน, เล่นซีน และการเพิ่มองค์ประกอบเดิมทุกอย่าง
- ปรับเฉพาะ `src/routes/index.tsx` และ `src/components/editor/ScenesPanel.tsx`; ไม่แก้ไฟล์คำนวณเสียง ซับ ซีน การเรนเดอร์ หรือส่งออก

## การตรวจรับ
- เปิดพรีวิวจริงทั้ง desktop และ mobile ใน Dark/Light mode เพื่อตรวจการจัดวางและข้อความไม่ล้น
- ตรวจปุ่ม สวิตช์ และเมนูเดิมว่ายังแสดงครบและกดได้
- รัน `bun run guard:lao` แบบเต็ม และไม่ส่งงานหาก CER, layout, UI integration หรือช่วงเวลาซ้อนกันแย่ลง

## ขอบเขตรอบนี้
ทำเฉพาะข้อ 1 และข้อ 4 ตามลำดับความสำคัญที่กำหนด ส่วนหน้าสไตล์ซับ ตัวแก้คำบรรยาย และไทม์ไลน์คำยังไม่เปลี่ยนในรอบนี้
