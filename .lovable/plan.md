# ปรับหน้าเลือกสไตล์และแก้คำบรรยาย

## เป้าหมาย
จัดโครงสร้างหน้าสไตล์ซับใหม่ตามภาพอ้างอิง โดยคงธีม OneRunAI และใช้เฉพาะค่าที่ระบบรองรับอยู่แล้ว

## สิ่งที่จะเปลี่ยน
- จัดหัวหน้าสไตล์เป็นปุ่มย้อนกลับ แท็บ “เลือกสไตล์ / แก้คำบรรยาย” และทางลัด “ปรับแต่ง Ani” ที่เชื่อมกับการตั้งค่าแอนิเมชันเดิม
- ปรับหมวดสไตล์เดิมทั้ง 3 หมวด (สไตล์คงที่, แอนิเมชัน, ของฉัน) และกริดตัวอย่าง 2 คอลัมน์ ให้แสดงคำว่า “ตัวอย่าง” ด้วยฟอนต์ สี ขอบ เงา และพื้นหลังของ preset จริง
- เพิ่มตัวควบคุมตำแหน่งและขนาดด้านล่างด้วยค่า `posY` และ `size` เดิม โดยไม่สร้างค่าหรือพฤติกรรมใหม่
- จัดหน้าแก้คำบรรยายให้มีตัวอย่างปัจจุบัน ฟอนต์ ขนาด รูปแบบ B/I เงา ขอบ สี และความหนา โดยผูกกับ `CaptionStyle` เดิมทั้งหมด
- คงเครื่องมือขั้นสูงเดิม เช่น karaoke, การจัดบรรทัด, ตำแหน่ง X/Y, animation speed, plate และสไตล์แยกรายบรรทัดไว้ในส่วนพับเก็บ เพื่อไม่ให้ฟีเจอร์เดิมหาย

## ขอบเขตที่ไม่เพิ่ม
- ไม่เพิ่ม underline หรือความกว้างกรอบ เพราะโมเดลสไตล์ปัจจุบันไม่มีค่าดังกล่าว
- ไม่เปลี่ยนหน่วยจริงจากเปอร์เซ็นต์เป็น px เพื่อหลีกเลี่ยงผลต่อการเรนเดอร์วิดีโอ; UI จะแสดงหน่วยตามค่าจริงของระบบ
- ไม่แตะการถอดเสียง การส่งออก การวาดซับ หรือการคำนวณเวลา

## การตรวจสอบ
- ตรวจการเลือก preset, บันทึก/ลบสไตล์ส่วนตัว, ฟอนต์, B/I, เงา, ขอบ, สี, ตำแหน่ง, ขนาด และ animation ว่ายังอัปเดตเหมือนเดิม
- ตรวจภาพ desktop/mobile ใน dark/light mode รวมถึงการไม่ล้นและ footer controls
- รัน `bun run guard:lao` แบบเต็มจนผ่านทุกด่าน
