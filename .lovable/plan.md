# อนิเมชันซับใหม่ 5 แบบ + การ์ดพรีวิวหน้าเลือกสไตล์

## แยกการเลื่อนแผงแก้ไขและพรีวิว
- เดสก์ท็อป: ล็อกพื้นที่ทำงานให้สูงพอดีกับหน้าจอ โดยหัวเว็บและแถบสถานะไม่ถูกนับรวมในพื้นที่เลื่อน
- แผงแก้ไขซ้ายมี scrollbar และ overscroll ของตัวเอง; พรีวิวขวามีพื้นที่อิสระจึงไม่เคลื่อนตามแผงซ้าย
- หากพรีวิวสูงเกินจอ จะเลื่อนได้เฉพาะภายในฝั่งขวาโดยไม่กระทบฝั่งแก้ไข
- มือถือคงการเรียงแนวตั้งและการเลื่อนหน้าปกติ ไม่บังคับความสูงหรือ sticky แบบเดสก์ท็อป
- ตรวจ desktop/mobile, dark/light และรัน `bun run guard:lao` แบบเต็มก่อนปิดงาน

## แก้ความคมชัดของการ์ดพรีวิว
- ปรับ token พื้นหลังพรีวิวเป็นกรมท่าเข้มที่แยกจากสีดำ และใช้ข้อความสว่างเฉพาะสำหรับพื้นหลังนี้ทั้งโหมดสว่าง/มืด
- ปรับการ์ดสไตล์คงที่ ของฉัน และอนิเมชัน ให้ชื่อ ป้ายสถานะ และข้อความตัวอย่างมี contrast ชัดเจนด้วยสีธีม OneRunAI
- ย่อ entrance ของ keyframes ให้อยู่ช่วงต้น 10–20% และคง opacity เต็มในช่วงส่วนใหญ่ของ loop
- ตรวจภาพจริงหลายจังหวะของ loop ทั้ง dark/light และทั้งโหมดทีละคำ/ทั้งประโยค
- รัน `bun run guard:lao` แบบเต็ม และบันทึกผลครบทั้ง 6 ด่านก่อนส่งงาน

### ผลตรวจล่าสุด
- ภาพจริงทั้งสองธีม: พื้นหลัง `oklch(0.205 0.045 267)`, ตัวอักษร `oklch(0.985 0.004 250)`, opacity `1`; ไม่มี console error
- การ์ดสไตล์คงที่และอนิเมชันอ่านชัด และลดเส้นขอบ/เงาเฉพาะภาพย่อโดยไม่เปลี่ยนสไตล์วิดีโอจริง
- TypeScript ผ่าน; guard ผ่าน CER/WER, layout 84/84, code-switch, overlap และ UI integration 84/84
- Full guard ยังไม่จบ: การถอดเสียงคลิปยาวในด่าน (จ) ค้างที่บริการถอดเสียง แม้รีสตาร์ตหน้าพรีวิวและรันรอบสะอาดหลายครั้ง จึงยังไม่บันทึกงานนี้ว่า guard ผ่านครบ

## ขอบเขตที่ทำเสร็จ
- `src/lib/captions.ts`: เพิ่ม `CaptionAnimation` 5 แบบ — `slideUp2` (สไลด์2), `glow` (เรืองแสง),
  `highlight` (ไฮไลต์), `karaokePlus` (คาราโอเกะ+), `karaoke2` (คาราโอเกะ2);
  เพิ่ม `animationModes` (แต่ละแบบใช้ได้กับโหมด ทีละคำ/ทั้งประโยค) และสีธีม
  `ACCENT_PRIMARY_HEX` / `ACCENT_SECONDARY_HEX` ใช้ร่วมกันทั้งพรีวิวและ export
- พรีวิว (`CaptionOverlay.tsx`): สไลด์2 = เข้าจากด้านข้าง + overshoot (ต่างจาก slideUp ที่มาจากด้านล่าง),
  เรืองแสง = text-shadow ม่วงกระพริบ, ไฮไลต์ = แถบม่วงไล่ขึ้นจากด้านล่างบรรทัด,
  คาราโอเกะ+ = สีไล่ตามคำ + ขยาย/ยกคำที่กำลังพูด, คาราโอเกะ2 = สีไล่จากบนลงล่างในคำ
- Export จริง (`burn-render.ts` ใช้ร่วมกันทั้ง WebCodecs และ MediaRecorder): วาดทั้ง 5 แบบด้วย canvas
  ให้ตรงกับพรีวิว (translate ทั้งบล็อกสำหรับสไลด์2, shadow ม่วงสำหรับเรืองแสง, roundRect แถบไฮไลต์,
  scale รอบกึ่งกลางคำสำหรับคาราโอเกะ+, clip บน/ล่างสำหรับคาราโอเกะ2) — ทุกคำยังถูกวาดครบ
- `StylePicker.tsx`: แท็บ "อนิเมชัน" เป็นกริดการ์ดอนิเมชันจริง เล่นวนอัตโนมัติในการ์ด
  ใช้ข้อความตามภาษาที่เลือก (`sampleTextForLanguage`) + สับแท็บ "ทีละคำ/ทั้งประโยค"
  ที่กรองรายการตาม `animationModes` และตั้ง `wordsPerGroup` ให้สอดคล้อง
- `src/styles.css`: keyframes `cap-*` และคลาส `.cap-demo-*` ใช้ตัวแปรสีธีม (`--accent-primary/secondary`)
  จึงถูกต้องทั้งโหมดสว่างและมืด

## เรื่อง guard ช้า (ด่าน ค)
สาเหตุคือแต่ละกรณีใน 84 กรณีโหลดฟอนต์ใหม่ (`ensureCaptionFonts`) และวาดพื้นหลัง 1080x1920 ทุกเฟรม
แก้เฉพาะ `scripts/lao-subtitle-guard.ts` (ไม่แตะโค้ดแอป): โหลดฟอนต์ครั้งเดียวต่อ family+weight,
ใช้ผืนภาพต้นทางขนาด 8x8, ปิด `smoothCuts` ตอนทดสอบ — ขอบเขตการตรวจเท่าเดิมครบ 84 กรณี

## การตรวจรับ
- `bun run guard:lao` เต็มรูปแบบ: ✅ PASSED ครบ 6 ด่าน — (ก) CER/WER 0.000 เท่า baseline,
  (ข) layout/burn 84/84, (ค) integration ผ่าน UI 84/84, (ง) ซับหาย 0 จุด,
  (จ) คลิปยาว 27.5 วิ ช่องว่างรวม 0.49 วิ, (ฉ) code-switching ผ่าน
- Playwright: แท็บอนิเมชัน โหมดทั้งประโยค 9 การ์ด / ทีละคำ 14 การ์ด แสดงตัวอย่างเล่นวนจริง
- ไม่แตะ logic ถอดเสียง/ตัดเงียบ

# แบ่ง/เพิ่มซีนเอง (manual scene split)

## ขอบเขตที่ทำเสร็จ
- `src/lib/scenes.ts`: เพิ่ม `splitSceneAt(scenes, time)` — แบ่งซีนที่ครอบคลุมเวลานั้นเป็นสองซีน
  (ไม่แบ่งถ้าใกล้ขอบซีนน้อยกว่า `MIN_SPLIT_GAP` = 0.3 วินาที), แยก `segments` ตรงจุดตัด,
  แบ่งข้อความตามสัดส่วนเวลา, จัด `index` ใหม่ต่อเนื่อง
  ซีนแรกคง `id` เดิม ซีนที่สองได้ `id` ใหม่ `<เดิม>+<เวลา>` (เสถียร ไม่ชนกันเมื่อแบ่งซ้ำ)
- `reassignElementsAfterSplit(elements, oldScene, newScenes)`: element (Motion/Sound/ViralText/B-roll)
  ที่ timing อยู่หลังจุดแบ่ง จะย้าย `sceneId`/`id` ไปซีนที่สองและปรับ `offset` ให้สัมพัทธ์กับ start ใหม่
  ส่วนที่อยู่ก่อนจุดแบ่งคงเดิม
- `src/routes/index.tsx`: เพิ่ม state `splitPoints` (บันทึกลงงานที่เซฟไว้ผ่าน `project-store`)
  และ `scenes` = ผลของ `splitSceneAt` ทับบน `buildScenes(segments, words)` ตามลำดับเวลา
  ล้าง `splitPoints` เมื่ออัปโหลดไฟล์ใหม่ ทำให้ทุกเส้นทาง (พรีวิว motion/B-roll, drop scene, export) ใช้ซีนชุดเดียวกัน
- `ScenesPanel.tsx`: ปุ่มกรรไกรสีม่วง (theme token) ในการ์ดซีน — แบ่งตรง playhead ถ้าอยู่ในซีนนั้น
  ไม่งั้นแบ่งกึ่งกลางซีน; ปิดปุ่มเมื่อซีนสั้นกว่า 0.6 วินาที

## Backward compatible
- ไม่มี `splitPoints` = พฤติกรรมเดิมจากการตัดเงียบอัตโนมัติทุกประการ
- ไม่แตะ `transcribe.server.ts`, `forced-align.ts`, `audio.ts`

## การตรวจรับ
- typecheck ผ่าน; ทดสอบ `splitSceneAt`/`reassignElementsAfterSplit` โดยตรง: แบ่งที่ 5 วินาทีของซีน 0–10
  ได้ 2 ซีน index 0/1 และ Viral text ที่ offset 7 ย้ายไปซีนที่สองด้วย offset 2, Motion ยังอยู่ซีนแรก
- `bun run guard:lao`: (ก) CER/WER 0.000 เท่า baseline, (ข) layout/burn 84/84, (ง) ซับหาย 0 จุด,
  (ฉ) code-switching ผ่าน — ส่วน (ค) integration ผ่าน UI ใช้เวลานานมากและยังรันค้างอยู่ตอนปิดงาน

# ข้อความตัวอย่างสไตล์ตามภาษาถอดเสียง

## ขอบเขตที่ทำเสร็จ
- `src/lib/captions.ts`: `sampleTextByLanguage` = คำเดียวต่อภาษา (lo: "ຕົວຢ່າງ", th: "ตัวอย่าง",
  en: "Example") และ helper `sampleTextForLanguage(language)` — fallback ไทยเมื่อไม่รู้จักภาษา
  (คำลาวมีวรรณยุกต์ ່ และสระ ົ / າ ครบ ใช้ทดสอบการแสดงผลสไตล์ได้)
- `StylePicker.tsx`: `PresetPreview` รับ `text` prop; การ์ดทุกแท็บ (สไตล์คงที่/อนิเมชัน/ของฉัน) ใช้ข้อความตามภาษา
  ผ่าน prop `language` ใหม่ — สไตล์ (สี/ฟอนต์/stroke/shadow) apply เหมือนเดิมทุกอย่าง
- `StyleControls.tsx`: กล่องพรีวิวหน้า "แก้คำบรรยาย" ใช้ `sampleTextForLanguage(language)` เช่นกัน
- `src/routes/index.tsx`: ส่ง `language={languages[0] ?? "th"}` ให้ทั้งสองคอมโพเนนต์ — reactive ทันทีเมื่อสลับภาษา
- `scripts/lao-subtitle-guard.ts`: ทำให้ด่าน (ค) เสถียรขึ้น — ใช้ locator ของ input ไฟล์ตัวแรกพร้อม timeout 90 วิ
