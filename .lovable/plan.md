# ปรับแผงคำบรรยายและ AI Tools ตาม reference

## เป้าหมาย
จัดโครงสร้างหน้าตาแผงเครื่องมือหลักให้ใกล้ภาพอ้างอิง โดยคงธีมม่วง–จักรวาล OneRunAI และการทำงานเดิมทุกอย่าง

## สิ่งที่จะทำ
- เพิ่มแถวการ์ดนำทาง 3 ใบขนาดเท่ากัน: คำบรรยาย, แก้ซีน, ตัดวิดีโอ โดยเชื่อมกับแท็บเดิม
- จัดรายการ “เครื่องมือ AI” ใหม่เป็นแถวไอคอน ชื่อ คำอธิบาย ปุ่มตั้งค่าที่มีอยู่เดิม และสวิตช์สีหลักของธีม
- แสดงเฉพาะเครื่องมือที่มีจริง: AI Subtitles และทางลัดไปตั้งค่า Viral Text, Sound, Motion Graphic, B-roll ที่มีอยู่ในแผงซีน
- แยก “ปรับแต่งวิดีโอ” ด้วยเส้นคั่น และคงเครื่องมือตัดช่วงเงียบกับ slider เดิม โดยจัด label/ค่า/แถบให้ตรงโครงสร้างภาพ
- คงส่วนภาษา การแปล ลดเสียงรบกวน งานที่บันทึก และปุ่ม Export ไว้โดยจัดลำดับให้อ่านง่ายขึ้น

## ขอบเขตทางเทคนิค
- แก้เฉพาะ JSX/คลาสหน้าตาใน `src/routes/index.tsx`; ไม่แก้ state, handler, การถอดเสียง, การเรนเดอร์, ซีน หรือ export logic
- ใช้ semantic theme tokens ที่มีอยู่ เช่น `primary`, `secondary`, `border`, `muted-foreground` เท่านั้น

## การตรวจรับ
- เปิดดูและกดนำทางจริงบน desktop/mobile ทั้ง dark/light mode พร้อมตรวจข้อความไม่ล้นและ controls เดิมยังอยู่ครบ
- รัน `bun run guard:lao` แบบเต็ม และต้องผ่านครบทุกด่านก่อนส่งงาน
