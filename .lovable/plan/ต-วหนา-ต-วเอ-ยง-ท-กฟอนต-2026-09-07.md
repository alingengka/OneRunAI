# ตัวหนา (Bold) / ตัวเอียง (Italic) แบบสังเคราะห์ ใช้ได้กับทุกฟอนต์

วันที่: 2026-09-07

## ที่มา
ไฟล์ฟอนต์แต่ละชุด (รวมฟอนต์ลาว 7 แบบที่เพิ่งเพิ่ม) มีน้ำหนักเดียว จึงไม่มีไฟล์ bold/italic จริง
ต้องสังเคราะห์ให้ได้ทั้งในพรีวิว (CSS) และในไฟล์ที่เรนเดอร์ออกไป (canvas)

## สิ่งที่ทำ
- `src/lib/captions.ts`
  - `CaptionStyle.bold/italic` และ `LineStyle.bold/italic` (รายบรรทัด override ได้)
  - `ITALIC_SKEW = -0.22` (~12.4°) และ `emphasizedWeight(weight, bold)` → `min(900, max(700, weight+200))`
- `src/lib/media/burn-render.ts`
  - `paintEmphasized(ctx, text, x, y, fontSize, em, mode)`
    - เอียง: `ctx.translate(x,y)` → `ctx.transform(1,0,-0.22,1,0,0)` → วาดที่ (0,0) → `restore()`
      (skew รอบจุด baseline ทำให้สระ/วรรณยุกต์ลาวเลื่อนตามตัวอักษร ไม่หลุดตำแหน่ง)
    - หนา: วาดซ้อน 9 ครั้ง offset `max(0.6, fontSize*0.018)` รอบทิศ + เพิ่ม `lineWidth` ของ stroke อีก `fontSize*0.02`
    - ใช้กับทั้ง `strokeText` และ `fillText` (ขอบดำ + ตัวขาว สอดคล้องกัน)
  - `emphasisPad()` เผื่อความกว้าง layout (bold 3.6% + italic 5% ของ fontSize) กันคำชนกัน
  - ใช้ทั้งใน `drawCaption` (รายบรรทัด) และ `drawViralText`
- พรีวิว: `CaptionOverlay.tsx` (ระดับสไตล์หลัก + รายบรรทัด) และ `ViralTextOverlay.tsx` ใช้ `font-weight`/`font-style: italic` และเพิ่ม `-webkit-text-stroke: currentColor` เมื่อ `bold` เพื่อบังคับให้เห็นตัวหนาในทุกเบราว์เซอร์แม้ฟอนต์มีน้ำหนักเดียว
  - ความหนาของ stroke = `fontSize * 0.035` (px) ให้หนาขึ้นใกล้เคียงกับ export จริงโดยไม่กลายเป็นก้อนหมึก
  - ใช้ `currentColor` เดียวกับสีตัวอักษร จึงไม่กลายเป็นเส้นขอบแยก
- UI: ปุ่ม **B** / **I** อิสระจากกัน ใน `StyleControls.tsx` (สไตล์หลัก + ต่อบรรทัด) และใน `ScenesPanel.tsx` (viral text แต่ละอัน)
- `scenes.ts`: `updateSceneElementFormat()` + `bold/italic` บน `SceneElement`, `ViralTextHit`; `motion.ts`: `MotionElement.bold/italic`

## ผลทดสอบจริง (Playwright, canvas เส้นทางเดียวกับ export)
ข้อความทดสอบลาวที่มีสระ/วรรณยุกต์ซับซ้อน: `ເບິ່ງນີ້ເລີຍ ຫ້າມພາດ`
วัด "ปริมาณหมึก" (พิกเซล alpha>40) เทียบ plain และวัด shear (ค่าเฉลี่ย x ครึ่งบน − ครึ่งล่าง)

| ฟอนต์ | bold/plain | both/plain | shear plain → italic |
|---|---|---|---|
| Archivo Black (fallback ลาว) | 1.29 | 1.30 | 2 → 23 |
| Inter | 1.28 | 1.27 | 67 → 80 |
| Kanit | 1.28 | 1.27 | 84 → 97 |
| Lao Chalk | 1.68 | 1.71 | 76 → 89 |
| PB Champasak | 1.47 | 1.50 | 76 → 95 |
| Tiktok Lao | 1.52 | 1.53 | 67 → 84 |
| Touk2 | 1.44 | 1.46 | 82 → 96 |
| Hinsiew | 1.52 | 1.55 | 62 → 77 |
| Lao Handwriting 16 | 1.40 | 1.40 | 57 → 68 |
| PB Melon | 1.58 | 1.63 | 52 → 66 |

- ตัวหนาเห็นชัดทุกฟอนต์ (หมึกเพิ่ม 28–71%)
- เอียงเพิ่ม shear +13 ถึง +21 px ทุกฟอนต์ (skew ทำงานจริง)
- ตรวจภาพ `/tmp/browser/bi/bi.png`: สระบน/ล่างของลาวยังอยู่ตรงตำแหน่งเดิมเทียบตัวอักษรเมื่อเอียง ไม่หลุด ไม่ทับกัน
- `bunx tsgo --noEmit` ผ่าน

## แก้ไขปัญหา: Bold ไม่เห็นในพรีวิวหน้าตัดต่อ (2026-09-07)

**สาเหตุ:** Chrome ไม่สังเคราะห์ `font-weight` ให้ฟอนต์ custom ที่มีน้ำหนักเดียว ทำให้พรีวิวดูไม่หนาแม้ export จะหนาถูกต้อง

**แก้ไข:**
- `src/components/editor/CaptionOverlay.tsx`
  - เพิ่ม `WebkitTextStroke: currentColor` ลงในแต่ละคำ (`<span>`) เมื่อ `style.bold` หรือ `lineStyles[li].bold` เปิดอยู่
  - ความหนา stroke = `fontSize * 0.035 px` (ปัดขึ้นขั้นต่ำ 1 px บนจอความละเอียดต่ำ)
- `src/components/editor/ViralTextOverlay.tsx`
  - เพิ่ม `WebkitTextStroke: currentColor` เมื่อ `hit.bold`

**ผลทดสอบพรีวิว (Playwright, `/test-bold` ชั่วคราว แล้วลบ):**
- ทุกฟอนต์ (Archivo Black, Inter, Kanit, Lao Chalk, PB Champasak, Tiktok Lao, Touk2, Hinsiew, Lao Handwriting 16, PB Melon) แสดงตัวหนาชัดเจนในพรีวิวเมื่อเปิด Bold
- ตัวอักษรไม่กลายเป็นก้อนหมึก ยังอ่านออกทุกตัว
- Italic ยังเอียงปกติ ไม่ได้รับผลกระทบจาก stroke
- ภาพประกอบ (plain / bold / italic): `/tmp/browser/bold-preview/screenshots/bold_preview.png`
- `bunx tsgo --noEmit` ผ่าน
