# Demo ธีม OneRunAI สำหรับหน้าตัดต่อ

## เป้าหมาย
ทำเดโมทิศทางภาพลักษณ์ใหม่เฉพาะหน้าตัดต่อหลักและแถบด้านบน โดยคงพฤติกรรมการตัดต่อ การถอดเสียง และการส่งออกเดิมทั้งหมด

## สิ่งที่จะทำ
- สร้างโลโก้ OneRunAI แบบ SVG สองเวอร์ชันตามคำอธิบาย: วงแหวนม่วง–ลาเวนเดอร์ไม่เต็มวง จุดแสงสีขาว และพื้นหลังโค้งมน
- เพิ่ม wordmark และแถบด้านบนแบบใหม่ พร้อมสวิตช์สลับ Dark/Light ที่จำค่าบนอุปกรณ์ โดย Dark เป็นค่าเริ่มต้น
- เปลี่ยนชุดสีกลางให้ตรง style guide ทั้งสองโหมด และเพิ่ม token สำหรับพื้นหลัง การ์ด แสง glow ข้อความ ขอบ และเงา
- ปรับหน้าตัดต่อหลัก การ์ด แท็บ และปุ่มสำคัญ เช่น “สร้างซับด้วย AI” และ Export ให้เห็นทิศทาง purple-glow cosmic โดยไม่เปลี่ยนลำดับงานหรือฟังก์ชัน
- เพิ่มแสงฟุ้ง เส้น orbit และ grain แบบบาง พร้อมลด motion ตามการตั้งค่าระบบ
- เปลี่ยนชื่อแบรนด์และข้อมูลหน้าเป็น OneRunAI โดยยังไม่สร้าง Landing Page เต็ม

## ขอบเขตไฟล์
แก้เฉพาะไฟล์ภาพ โลโก้ ชุดสี และส่วนแสดงผล ได้แก่ CSS, หน้าเว็บ, UI component และ branding metadata เท่านั้น ไม่แก้ไฟล์ logic เสียง ซับ การจัดเวลา หรือ export

## การตรวจรับ
- เปิดดูจริงทั้งจอ desktop และ mobile ใน Dark/Light เพื่อตรวจการวางหน้า การอ่านตัวอักษร และการสลับธีม
- ทดสอบว่าปุ่มหลักและขั้นตอนเดิมยังอยู่ครบ
- รัน `bun run guard:lao` แบบเต็ม และจะไม่ส่งงานหากค่า CER, การวาดซับ, UI integration หรือช่วงเวลาซ้อนกันแย่ลง

## สมมติฐานสำหรับเดโม
wordmark ใช้ฟอนต์ heading ของหน้า และโลโก้ SVG เป็นภาพใกล้เคียงตามคำบรรยายก่อน เมื่อได้รับไฟล์ต้นฉบับจึงค่อยปรับรูปทรงให้ตรงยิ่งขึ้น
