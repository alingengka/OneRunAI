# แก้ระบบซิงก์ซับ ตัด Dead-air และส่งต่อ CapCut

## เป้าหมาย
ทำให้ทุกขั้นใช้งานบนเส้นเวลาเดียวกันตั้งแต่อัปโหลด วิเคราะห์เสียง ซิงก์คำ แก้คำ ตัดช่วงเงียบ ใส่เสียง Animation จนถึงส่งออกเข้า CapCut โดยไม่ทำให้เวลาซับคลาดหลังตัด

## สิ่งที่จะทำ

### 1. ซับตรงเสียงระดับคำและตรวจซิงก์ซ้ำได้
- เปลี่ยนการถอดเสียงให้รับ timestamp ระดับคำจากโมเดลโดยตรง แทนการเฉลี่ยเวลาจากความยาวคำเป็นหลัก และเก็บ fallback เฉพาะกรณีบริการไม่คืน timestamp
- รักษา mapping ระหว่าง “เวลาคลิปต้นฉบับ” กับ “เวลาหลังตัด dead-air” ในทุกคำ
- เพิ่มปุ่ม **ตรวจซิงก์แล้วลองใหม่** เพื่อตรวจคำที่เวลาทับกัน สั้น/ยาวผิดปกติ หรือมีช่องว่างน่าสงสัย และถอดเสียงเฉพาะช่วงที่มีปัญหาใหม่ด้วยช่วงเสียงที่แคบลง
- แสดงรายการช่วงที่เพี้ยน กดแล้วกระโดดไปก่อนช่วงนั้นเล็กน้อยและเล่นตัวอย่างวนสั้น ๆ ได้

### 2. แก้ Dead-air ให้ตัดจริง
- แก้อัลกอริทึมตรวจความเงียบให้สะสม silence run อย่างถูกต้อง (ปัจจุบันจุดเริ่ม silence ถูกเลื่อนทุกเฟรม จึงแทบไม่เคยตัด)
- วิเคราะห์เสียงรวมทุก channel, ปรับ noise floor แบบ adaptive, รวมช่วงพูดที่ติดกัน และคง padding รอบคำเพื่อไม่ตัดพยางค์ต้น/ท้าย
- เพิ่มแถบ timeline ที่เห็นช่วงเก็บ/ช่วงตัดชัดเจน กดช่วงเพื่อฟังก่อน–หลัง และอนุญาตเปิด/ปิดช่วงตัดเฉพาะจุด
- แก้ renderer ให้รอ metadata อย่างปลอดภัย, รักษา audio track, เลือก MP4 เมื่อเบราว์เซอร์รองรับและ fallback เป็น WebM พร้อมตรวจว่าไฟล์ผลลัพธ์มีข้อมูลจริงก่อนดาวน์โหลด

### 3. แก้ข้อความและเวลาแบบเจาะจง
- เพิ่ม word timeline แบบคลิกเลือกคำหรือ drag เลือกช่วงคำ
- แผงแก้ไขจะเปลี่ยนข้อความ เวลาเริ่ม/จบ และเลื่อนเวลาแบบละเอียดได้ โดยอัปเดต preview, karaoke groups, transcript และ export ทันที
- รองรับแยกคำ/รวมคำ และป้องกันเวลาเหลื่อมหรือเรียงย้อนกัน
- การแก้ทั้งหมดบันทึกกลับเข้า autosave เดิม รวมถึงสถานะช่วง dead-air ที่ผู้ใช้ปรับเอง

### 4. ส่งออกสำหรับ CapCut แบบแก้ต่อได้จริง
- ใช้ trimmed timeline เป็นแหล่งข้อมูลเดียว แล้วส่งออก **วิดีโอที่ตัดจริง + SRT ที่ remap แล้ว** ซึ่ง CapCut เปิดและแก้ caption ต่อได้
- เพิ่ม “CapCut Package” ที่รวมไฟล์วิดีโอ, SRT และ manifest เวลาไว้เป็นชุดเดียว พร้อมชื่อไฟล์ที่สัมพันธ์กัน; XML/EDL จะเก็บเป็นตัวเลือกเสริม ไม่อ้างว่าเป็นไฟล์โปรเจกต์ CapCut โดยตรง
- ให้ subtitle timing, cut points และ animation SFX ใช้ mapping เดียวกัน เพื่อไม่เหลื่อมหลังนำเข้า
- ตรวจ download flow และชื่อไฟล์บนเบราว์เซอร์จริง

### 5. Sound effects สำหรับ Animation
- เพิ่มแพ็กเสียงที่สร้างด้วย Web Audio แบบไม่ติดลิขสิทธิ์ เช่น Clean, Punch, Soft และ Digital พร้อม mapping ที่เหมาะกับ Pop, Slide, Typewriter, Bounce, Zoom, Karaoke, Shake และ Flip
- เพิ่มเปิด/ปิด, เลือกแพ็ก, ปุ่ม Preview และ slider ระดับเสียง
- เล่นเสียงใน preview ตามจังหวะคำ/กลุ่มโดยไม่ยิงซ้ำตอน seek และ mix เสียงเข้าไฟล์วิดีโอที่ export จริง
- บันทึกการตั้งค่าเสียงไว้กับโปรเจกต์

## รายละเอียดทางเทคนิค
- แยก schema/helper ออกจากไฟล์ `createServerFn` ให้ wrapper เป็น module ที่มีเฉพาะ imports/types/server function declaration ตามข้อกำหนดของ TanStack Start
- เพิ่ม utility กลางสำหรับ source↔trimmed time mapping, word validation และ deterministic SFX synthesis
- แยก UI timeline/editor และ sync diagnostics เป็น component ย่อย เพื่อไม่ให้ route หลักซับซ้อนขึ้น
- ใช้ design tokens และ Button components เดิม พร้อม layout ที่ทำงานได้ทั้งจอมือถือและ desktop

## การตรวจสอบ
- ทดสอบ silence detector กับเสียงจำลองที่มี speech/silence หลายช่วง รวม edge silence และ stereo
- ทดสอบ source↔trimmed mapping, SRT timing, การแก้คำ/เวลา, split/merge และการ retry เฉพาะช่วง
- ทดสอบในเบราว์เซอร์จริง: อัปโหลด → วิเคราะห์ → สร้างซับ → preview ช่วงเพี้ยน → แก้คำ → ตัด dead-air → preview SFX → export → ตรวจไฟล์วิดีโอและ SRT
- ตรวจ responsive ที่ viewport ปัจจุบันและ desktop รวมถึง console/runtime errors
