# Viral Clip Creator

อยากทำ mini app ที่สามารตตัดคลิปได้เป็น Short Video แบบ Viral Video 
1.อยากได้ text ที่สามารตปรับหรือแก้ไขเองได้ว่าอยากได้ที่ละคำหรือสองคำหรือหลายคำได้หมดตามต้องการ มี style text ให้เลือกหลากหลาย
2.สามารตตัด dead-air ออกได้หรือตรงที่เงียบไม่ได้พูดออกได้เอง 
3.และแบบอื่นๆตามตัวอย่างที่แนวใส่ใน Ref 
4.สามารตเชื่อมกับ Capcut ได้
และทุกปุ่มต้องสามารตใช้งานได้จริง
